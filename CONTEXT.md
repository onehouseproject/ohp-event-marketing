# Task routing

Maintained by hand. Add a row when a new workspace appears.

| If the user wants... | Go to |
|---|---|
| A skill, or any file an agent reads, to create or edit | `.agents/skills/writing-for-agents/SKILL.md` |
| Whether a skill is user-invoked or model-invoked, or how a harness adapter is written | `.agents/invocation.md` |
| Where a decision record or research memo goes and how it is named | `docs/README.md` |
| What is deferred or unfinished in the repository itself | `docs/open-items.md` |
| Run or change a repository script | `tools/README.md` |

## Not loaded by default

- `tmp/`: scratch and uploads, only when the task names it.
