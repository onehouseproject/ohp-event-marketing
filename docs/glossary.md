# OHP Event Marketing

The marketing pages One House Project publishes for its events, all served from one subdomain.

## Language

**Event**:
A real-world gathering One House Project runs, most often a fundraiser.
_Avoid_: Campaign, project

**Event Page**:
A web page that markets one Event and asks the visitor to take one action, such as buying a ticket. Usually one per Event; an Event may have more.
_Avoid_: Template, site, route, microsite

**Slug**:
The short name at the end of the web address that identifies one Event Page, such as `nye` in `events.onehouseproject.com/nye`. It is named for the Event and carries no year.
_Avoid_: Route, path
